# Delhi Transit Engine - Documentation & Reports

This directory contains hackathon deliverable documentation, technical specifications, and validation reports.

## Files
- `hackathon_problem_statement.pdf`: Transport Stack Hackathon 2026 - Problem 1 guidelines.
- `delhi_buses_gtfs_metadata.pdf`: Specification and schema for DTC/DoT GTFS feeds.
- `delhi_buses_gtfs_rt_instructions.pdf`: Instructions and API keys for GTFS-RT streaming feeds.
- `01_proposal.md`: Project proposal and system design.
- `02_technical_note.md`: Methodological details on map matching, segment speed estimation, and live telemetry fusion.
- `03_validation_report.md`: Comparative evaluation of journey estimates vs. observed trips and Google Maps.
