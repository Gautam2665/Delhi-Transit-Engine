# Frontend: Delhi Transit Journey Inspector

Next.js + MapLibre GL JS web UI for inspecting bus journeys, real-time traffic speeds, and route options.

## Features
- Interactive MapLibre GL vector map showing Delhi bus network, live bus locations, and route traces.
- Journey planner input form: origin, destination, departure time.
- Side-by-side journey options displaying:
  - Walk to first stop
  - Boarding stop, route name, alight stop, transfers
  - Estimated travel time based on empirical time-of-day speed model vs. static timetable vs. quiet hours
